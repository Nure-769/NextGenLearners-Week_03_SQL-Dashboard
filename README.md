# 📊 Week 3: SQL + Program Performance Dashboard

## 📌 Project Overview
This repository contains the Week 3 deliverable for the **NextGenLearners** internship. The primary objective of this project is to practice SQL querying across multiple related relational tables and build an interactive data visualization dashboard using **Streamlit** to analyze program performance, track completion rates, and identify top-performing interns.
